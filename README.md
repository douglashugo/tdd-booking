# TDD Booking

Projeto de exemplo para reservas (booking) com TypeScript, testes com Jest e foco em TDD.

## Requisitos

- Node.js e npm instalados

## Como executar

1) Instale as dependências:

```bash
npm install
```

2) Execute os testes:

```bash
npm test
```

## Estrutura básica

- `src/domain`: entidades, value objects e regras de negócio
- `src/application`: serviços e DTOs
- `src/infrastructure`: persistência, repositórios e controllers
